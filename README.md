# 🔥 熱愛バレた件｜Tinder ver

ひろとと Tinder で出会ったていで始まる、スマホ風SNSゲーム（単一HTML＋画像アセット、フレームワークなし）。元作『熱愛バレた件』のカスタマイズ版です。

▶ **プレイ:** https://v5m44g26fb-sudo.github.io/hiroto-tinder/
▶ **元作『熱愛バレた件』:** https://v5m44g26fb-sudo.github.io/hiroto-netsuai-bareta/

## あらすじ
Tinder で、ひろとから Super Like が来ていたことから始まる出会い。
私服の自撮りだけのプロフィール、職業は濁されたまま。なおは元々ひろとのファンなのに、連絡を取り合っている間は「似てるけど、まさか本人なわけない」と気づかない。
——でも、初デートで初めて会った瞬間、顔を上げたら「え、本物やん！？」

最初はひろと側も Tinder らしく気楽な遊びのノリ。会ってから少しずつ本気になっていく成長弧で、第2話『初デート』→第3話『告白』→付き合い始め→日常→第6話『バレた日』（炎上編）へ繋がります。

## 遊び方
1. ロック画面をタップして解除し、ホームの Tinder アイコンを開く。
2. ダミーカードを ✕ / ❤️ でめくると、ひろとのカードに Super Like バッジ（青枠）が付いて現れる。写真はタップで切り替え。
3. Like で「It's a Match!」→ Tinder内チャット（選択肢で返信）→ LINE交換で第2話へ。
4. LINE / X / Instagram / ニュース / 写真 / TikTok / 通話など、元作のアプリ群はそのまま遊べます。ホームのウィジェットから「⏩ 炎上編へスキップ」も可能。

## このverのポイント
- ひろとの Tinder プロフ写真は、私服自撮り（IG未掲載風）を使用。職業・認証バッジ・IGアカウントは最初は出さない。
- 彼のIGアプリは第1話中はロックされ、第2話で正体が分かってから開ける。
- なおのアカウント画像は初期アイコン（人型シルエット）を使用。本人の顔写真は使っていない。
- 通話・LINEボイスには元作と同じクローン音声を使用。

- これは **創作フィクション** です。実在の人物の交際事実などを示すものではありません。
- 写真は所有者が個人的な創作のために提供したもの、および公開投稿から取得したものを使用しています。
